# Review engine per repository — Implementation Plan

> Follow `AGENTS.md` and the `ub-mode` skill. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Each repository chooses the CLI that reviews it (Codex or Claude Code), its model and its effort, from the dashboard; the dashboard lists only installed CLIs and shows activity per repository, in a refreshed visual style.

**Spec:** section "Motor de revisão por repositório" of `docs/superpowers/specs/2026-10-31-pr-reviewer-design.md`.

## Review Focus

1. Claude Code must run read-only: `--restricted`, tools limited to Read/Grep/Glob (none for memorize), no MCP, no session files, inside the worktree.
2. An unknown or missing engine fails the review with one error comment and never silently uses another engine.
3. Old `repos.json` entries without `engine`/`effort` keep reviewing with Codex exactly as before.
4. Bash (`lib/repos.jq`) and Node (`dashboard/validate.js`) accept the same values.

- [ ] Implement in `lib/repos.jq`, `lib/repos.sh`, `dashboard/validate.js`, `repos.example.json`.
